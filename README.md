# gta6-trophy-rarity-forecast-01

Forecaster for GTA VI week-one trophy earn rates: reads a case's Exophase history, forecasts each trophy's earn-rate quantiles at the target horizon.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```

Deterministic, Node 22 stdlib only. `node tests/synthetic.mjs` verifies calibration on synthetic dynamics.
